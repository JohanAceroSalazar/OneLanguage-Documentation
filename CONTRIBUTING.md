# Contribuir a la documentación

Trabaje en una rama distinta de `main`. Describa la fuente, ruta y rama de cada afirmación técnica; marque lo que no esté comprobado como **NO VERIFICADO** y no exponga secretos ni datos personales. Mantenga enlaces relativos, Markdown compatible con GitHub y diagramas Mermaid válidos.

Antes de proponer cambios, verifique enlaces internos, identificadores RF/RNF/CU y que el código citado corresponda a la rama auditada. Actualice `docs/source-audit.md` si cambia una fuente o commit de referencia.
