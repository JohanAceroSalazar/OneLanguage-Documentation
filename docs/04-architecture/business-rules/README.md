# Reglas de negocio verificables

- Solo se deben comunicar reconocimientos de clases entrenadas y aceptadas por los umbrales del servicio IA.
- Los recursos de usuario, traducciones, permisos y accesibilidad requieren autenticación según `SecurityConfig`.
- La recuperación de contraseña usa tokens temporales; no se documentan valores ni mecanismos secretos.
- El perfil es de consulta en el alcance SRS; no se aprueba edición de datos personales desde esa sección.
