# Glosario

| Término | Definición |
| --- | --- |
| LSC | Lengua de Señas Colombiana. |
| Señal/seña soportada | Clase incluida en el entrenamiento y etiquetas del modelo. |
| Traducción | Registro del texto resultante y, opcionalmente, metadatos/grabación; no implica traducción lingüística total. |
| JWT | Token firmado usado por la API para autenticar solicitudes. |
| Accesibilidad | Preferencias de tamaño de texto, tema e idioma documentadas en el SRS. |
