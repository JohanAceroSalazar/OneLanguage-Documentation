# HU-03 — Recuperación de contraseña

Como usuario, quiero solicitar y completar el restablecimiento de contraseña para recuperar el acceso.

- Requisito: RF1.3. Prioridad: alta. Estado: **IMPLEMENTADO E INTEGRADO**; la entrega SMTP requiere validación en el ambiente configurado.
- Aceptación: la solicitud acepta correo; el restablecimiento exige token y nueva contraseña válidos.
