# HU-04 — Reconocimiento limitado

Como usuario, quiero usar la cámara para reconocer una seña soportada y ver su texto para apoyar la comunicación.

- Requisito: RF2.1–RF2.5. Prioridad: alta. Estado: **IMPLEMENTADO E INTEGRADO; PENDIENTE DE VALIDACIÓN EN EJECUCIÓN**.
- Aceptación: con permiso de cámara y una clase entrenada, el servicio devuelve una etiqueta estable; con permiso denegado, baja confianza o seña no soportada, la interfaz informa el estado sin afirmar reconocimiento.
