# Estructura web

`src/pages` contiene landing, login, registro, recuperación/restablecimiento, home, traducción, historial, perfil, accesibilidad y términos. `src/components` contiene navegación, ruta protegida, controles de marca, entrada, modal y bootstrap de tema. `src/services` contiene API, auth, sesión, traducción, permisos y almacenamiento/accesibilidad.
